Dale una tarea a [TabRunner](https://tabrunner.app) en Chrome. Lee páginas, hace clic y escribe en tus pestañas, con las cuentas en las que ya iniciaste sesión.

## Cómo funciona

- Elige tu proveedor de IA o conecta un modelo local.
- Las solicitudes van directamente de la extensión al proveedor que elijas.
- Aprueba el plan antes de empezar. El agente pide tu confirmación antes de pagar, enviar o borrar.
- Pide tareas desde el panel lateral, prográmalas para después o envíalas desde Claude Code o Codex.

La extensión, el sitio web y las herramientas para conectar apps de IA son de código abierto y están en [tabrunner/tabrunner](https://github.com/tabrunner/tabrunner).
