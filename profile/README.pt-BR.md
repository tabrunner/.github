Peça uma tarefa ao [TabRunner](https://tabrunner.app) no Chrome. Ele lê páginas, clica e digita nas suas abas, usando as contas em que você já está logado.

## Como funciona

- Escolha seu provedor de IA ou conecte um modelo local.
- Os pedidos vão direto da extensão para o provedor que você escolher.
- Aprove o plano antes de começar. O agente pede sua confirmação antes de pagar, enviar ou apagar.
- Peça tarefas pelo painel lateral, agende para depois ou envie pelo Claude Code ou Codex.

A extensão, o site e as ferramentas para conectar apps de IA têm código aberto em [tabrunner/tabrunner](https://github.com/tabrunner/tabrunner).
