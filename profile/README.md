Give [TabRunner](https://tabrunner.app) a task in Chrome. It reads pages, clicks and types using the tabs and accounts you're already signed into.

## How it works

- Choose your AI provider or connect a local model.
- Provider requests go straight from the extension to the provider you choose.
- Approve the plan before it starts. The agent asks before paying, sending or deleting.
- Give it tasks in the side panel, schedule them for later or send them from Claude Code or Codex.

The extension, website and tools for connecting AI apps are open source in [tabrunner/tabrunner](https://github.com/tabrunner/tabrunner).
